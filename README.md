# ProtoCross blog comments

This public repository stores comments for the [ProtoCross development blog](https://protocross.dev/blog/) using [Giscus](https://giscus.app/).

Comments live in the **Announcements** discussion category. A thread is created automatically when an article receives its first comment or reaction. You can participate on the blog or directly in GitHub Discussions.

Please keep discussions relevant to the article and respectful of other readers. Maintainers moderate comments using GitHub's discussion tools.

The blog source and unpublished drafts are maintained separately. This repository contains only comment configuration and public discussions.
